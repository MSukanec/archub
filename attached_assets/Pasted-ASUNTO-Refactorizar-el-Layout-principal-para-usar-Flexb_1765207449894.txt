ASUNTO: Refactorizar el Layout principal para usar Flexbox Vertical y corregir el cálculo de altura (Hero / Announcement Bar).

CONTEXTO: Actualmente, la aplicación tiene problemas de visualización en el Layout principal.

Cuando activo la barra de anuncios (AnnouncementBar) en la parte superior, el contenido principal (Hero) se empuja hacia abajo, generando un scroll vertical innecesario porque el Hero probablemente tiene una altura fija de 100vh.

Incluso sin la barra de anuncios, el layout no se siente robusto en diferentes tamaños de pantalla.

OBJETIVO TÉCNICO: Necesito cambiar la estrategia de layout de "alturas fijas" (h-screen) a un modelo de "Flexbox Vertical". El contenedor padre debe ocupar toda la pantalla, y el contenido principal debe expandirse para ocupar el espacio restante disponible, independientemente de si la barra de anuncios está visible o no.

INSTRUCCIONES DE IMPLEMENTACIÓN:

Coloca el AnnouncementBar y el Navbar al principio.

Envuelve el contenido principal (children o <Outlet />) en una etiqueta <main>.

CRÍTICO: Aplica la clase flex-1 (o flex-grow) a este <main>. Esto forzará al contenido a ocupar todo el espacio sobrante automáticamente.
