**ASUNTO:** Implementación de Tareas Programadas (Cron Jobs) - Notificaciones de Expiración de Suscripción.

**CONTEXTO:**
Nuestro sistema de suscripciones requiere pagos manuales para la renovación. Actualmente, los usuarios no reciben ninguna notificación cuando su plan está por expirar (GAP CRÍTICO). Necesitamos implementar un sistema automático que envíe correos recordatorios antes del vencimiento.

**OBJETIVO TÉCNICO:**
1. Configurar la infraestructura necesaria en nuestro backend (Express server) para ejecutar tareas programadas (Cron Jobs).
2. Crear la primera tarea programada: un job diario que verifique suscripciones próximas a vencer y envíe correos electrónicos usando Resend.

**REQUISITOS ESPECÍFICOS:**

**1. Infraestructura de Cron Jobs:**
* Instala una librería robusta para manejar cron jobs en Node.js, como `node-cron` (o sugiéreme la mejor opción para el entorno Replit actual).
* Crea una nueva carpeta para organizar esto: `server/cron/`.
* Crea un archivo principal `server/cron/index.ts` que inicialice y programe todos los jobs. Asegúrate de que este archivo se importe e inicie cuando arranca el servidor (`server/index.ts` o `app.ts`).

**2. Lógica del Job de Notificaciones (`server/cron/jobs/subscription-expiry-cNotifier.ts`):**
* Este job debe ejecutarse **una vez al día** (por ejemplo, a las 9:00 AM UTC).
* **Conexión a DB:** Debe usar el cliente de Supabase con `service_role` para poder consultar todas las suscripciones.
* **La Lógica de Consulta (CRÍTICO - IDEMPOTENCIA):**
    * Debe buscar en la tabla `organization_subscriptions` las suscripciones con estado `'active'`.
    * Debe calcular las fechas objetivo: dentro de 7 días, dentro de 3 días, y hoy (para las que vencen en < 24hs).
    * **MUY IMPORTANTE:** Para cada suscripción encontrada, debe verificar en la nueva tabla `public.subscription_notifications_log` si YA se envió ese tipo de notificación ('7_days_before', etc.) para esa suscripción. Si ya existe el registro, **SE DEBE IGNORAR** para no enviar correos duplicados.

* **El Envío del Correo:**
    * Para las suscripciones que necesitan aviso, obtén el email del administrador o dueño de la organización.
    * Usa la integración existente de Resend para enviar un correo HTML simple.
    * *Contenido del mail (ejemplo simple):* "Hola, tu suscripción al plan [Nombre del Plan] vence el [Fecha]. Por favor, renueva para evitar perder acceso."

* **Registro del Envío:**
    * INMEDIATAMENTE después de enviar el correo con éxito a Resend, inserta un registro en `subscription_notifications_log` con el `subscription_id` y el `notification_type` correspondiente.

**ENTREGABLES:**
* La instalación de la librería de cron.
* La estructura de carpetas `server/cron/`.
* El archivo de lógica del job bien documentado y robusto contra fallos.
* La integración en el arranque del servidor.
