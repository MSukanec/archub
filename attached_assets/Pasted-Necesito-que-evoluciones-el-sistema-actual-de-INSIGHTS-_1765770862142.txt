Necesito que evoluciones el sistema actual de INSIGHTS del dashboard de
"Gastos Generales" hacia un modelo NARRATIVO y EJECUTIVO.

IMPORTANTE:
- NO crear nuevos componentes visuales
- NO modificar el layout del dashboard
- Reutilizar InsightCard e InsightEngine
- Todo debe seguir siendo escalable para otros dashboards

--------------------------------------------------
1. ESTRUCTURA NARRATIVA DE UN INSIGHT
--------------------------------------------------

Cada Insight debe poder responder estas 3 preguntas implícitamente:

1) QUÉ pasó (hecho)
2) POR QUÉ pasó (causa)
3) QUÉ HACER / DÓNDE MIRAR (acción sugerida)

Esto NO significa agregar nuevos campos visuales,
sino enriquecer el contenido generado por cada regla.

--------------------------------------------------
2. EXTENDER EL TIPO INSIGHT (sin romper nada)
--------------------------------------------------

Extender el tipo Insight actual para soportar opcionalmente:

- context?: string
  (breve explicación del origen del dato)

- actionHint?: string
  (sugerencia clara y concreta)

Ejemplo interno (no hardcodeado):
{
  title: "Origen del aumento identificado",
  description: "El 42% del aumento proviene de Infraestructura.",
  context: "Infraestructura creció un 18% respecto al período anterior.",
  actionHint: "Revisá los conceptos de Infraestructura en este período."
}

--------------------------------------------------
3. APLICAR NARRATIVA A LOS INSIGHTS EXISTENTES
--------------------------------------------------

Actualizar las reglas actuales para que:

- Cada insight tenga:
  - description = QUÉ pasó
  - context = POR QUÉ pasó
  - actionHint = QUÉ HACER

Ejemplos esperados:

- CARGA OPERATIVA
  QUÉ: "Procesás en promedio 16 pagos por mes"
  POR QUÉ: "El 70% son pagos de bajo monto"
  QUÉ HACER: "Considerá consolidar pagos recurrentes"

- CONCENTRACIÓN
  QUÉ: "3 categorías explican el 78% del gasto"
  POR QUÉ: "Infraestructura lidera el crecimiento"
  QUÉ HACER: "Revisá Infraestructura en el gráfico de categorías"

--------------------------------------------------
4. JERARQUÍA Y PRIORIZACIÓN
--------------------------------------------------

Modificar InsightEngine para que:

- Priorice insights que:
  - expliquen variaciones grandes
  - estén vinculados a KPIs visibles
- Evite mostrar insights redundantes
- Máximo 3 insights activos

--------------------------------------------------
5. COMPORTAMIENTO SEGÚN PERÍODO
--------------------------------------------------

Los insights deben adaptarse al contexto temporal:

- Períodos cortos (≤ 30 días):
  - Insights operativos
  - Frecuencia, recurrencia, carga

- Períodos largos:
  - Tendencias
  - Concentración
  - Patrones sostenidos
