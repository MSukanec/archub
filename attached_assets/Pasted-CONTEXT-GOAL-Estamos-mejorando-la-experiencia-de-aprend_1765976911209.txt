CONTEXT & GOAL
---------------
Estamos mejorando la experiencia de aprendizaje dentro de la plataforma Seencel.
Existe un curso llamado "Master ArchiCAD Online" con varias tabs:

- VISIÓN GENERAL → ya tiene hero, progreso, métricas generales (NO tocar).
- REPRODUCTOR → ya tiene el video player y un sidebar para navegar lecciones (NO tocar).
- CONTENIDO → esta tab actualmente muestra una TABLA con módulos y lecciones, y queremos REDISEÑARLA COMPLETAMENTE.

El objetivo es reemplazar esa tabla por una experiencia PREMIUM, visual, clara y moderna, orientada a exploración del curso, NO a consumo directo (eso ya lo hace el Reproductor).

IMPORTANTE:
- NO duplicar el hero ni métricas de Visión General
- NO replicar el sidebar del Reproductor
- CONTENIDO debe funcionar como un "Course Structure Explorer"

------------------------------------------------

DESIGN & UX REQUIREMENTS
------------------------
La tab CONTENIDO debe mostrar:

### 1. Header simple
- Título: "Estructura del curso" (o similar)
- Subtítulo breve explicativo
- NO hero grande
- NO métricas de progreso global

### 2. Módulos del curso
Cada módulo debe mostrarse como una SECCIÓN visual (no cards enormes, no tabla).

Para cada módulo:
- Título del módulo
- Badge o texto secundario: cantidad de lecciones + duración total
- Estado visual sutil (pendiente / en curso / completado)
- Posibilidad de expandir / colapsar el módulo

El módulo activo (donde el usuario está cursando) debe:
- Estar expandido por defecto
- Tener una indicación visual sutil

### 3. Lecciones (dentro de cada módulo)
Cada lección debe ser un "Lesson Row" rica (NO una fila de tabla).

Cada lección debe mostrar:
- Ícono según tipo (video, tip, material, etc.)
- Título
- Duración
- Estado visual:
  - No vista
  - En progreso
  - Completada
- Acciones inline:
  - ▶️ Ver / Ir a la lección
  - ⭐ Marcar como favorito
  - 📝 Indicador de apuntes (si existen)

NO usar:
- columnas
- encabezados tipo tabla
- botones de tres puntitos para acciones primarias

------------------------------------------------

INTERACTIONS & DETAILS
----------------------
Agregar micro-interacciones sutiles:
- Hover suave en lecciones
- Transiciones al expandir módulos
- Estados visuales claros (visited / active / completed)

Comportamientos inteligentes:
- Auto-expandir el módulo activo
- Marcar la última lección vista
- Indicar la siguiente lección recomendada

------------------------------------------------

RESPONSIVE REQUIREMENTS
-----------------------
Desktop:
- Layout centrado
- Mucho espacio en blanco
- Lectura clara
- Jerarquía visual fuerte

Mobile:
- Diseño vertical
- Módulos colapsables
- Botones y áreas táctiles cómodas
- Nada debe sentirse “apretado”
