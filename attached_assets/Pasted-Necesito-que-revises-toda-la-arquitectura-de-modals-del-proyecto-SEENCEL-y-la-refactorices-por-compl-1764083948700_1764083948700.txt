- Renderizado mediante portal
- Soporte para stack de modals (modals apilados)
- Soporte para props dinámicas y type-safe
- Modo “panel”, “fullscreen”, “wizard” y “drawer mobile”
- Integración con dark/light mode sin duplicar estilos
- Separación TOTAL entre UI y lógica de negocio

📌 MODAL BASE: LO QUE TIENE QUE TENER
------------------------------------------------------
Construir un componente <ModalBase /> con:

- Overlay con animación
- Animaciones de entrada/salida (scale+fade estilo Linear)
- Focus trap
- Cerrar con ESC (opcional)
- Cerrar clic afuera (opcional)
- Portal a document.body
- Tamaños: sm | md | lg | xl | fullscreen
- Sticky footer opcional
- Dark/light 100% con variables CSS
- Scroll interno SOLO en el body
- Header limpio con botón cerrar (X)
- Footer con acciones
- Variantes mobile: auto-detectar mobile y usar <DrawerBase />

TODOS los modals del sistema deben usar este ModalBase.

------------------------------------------------------
📌 MODAL STORE (Zustand)
------------------------------------------------------
Crear un store global con:

- isOpen
- stack: array de modals abiertos
- type: string con el identificador del modal
- props: object dinámico con los datos del modal
- funciones:
   - openModal(type, props?)
   - closeModal()
   - closeAll()
   - pushModal(type, props?)    // apilar uno encima
   - popModal()                 // cerrar sólo el superior

Debe ser completamente type-safe con TypeScript.

------------------------------------------------------
📌 MODAL REGISTRY
------------------------------------------------------
Crear un archivo:
src/components/modals/ModalRegistry.ts

Contendrá un diccionario:
{
   CREATE_PROJECT: <CreateProjectModal />,
   EDIT_CLIENT: <EditClientModal />,
   PAYMENT_MATERIAL: <PaymentMaterialModal />,
   IMPORT_MATCHER: <UniversalMatcherModal />,
   ...
}

Cada modal se referencia por KEY, no por import local.

------------------------------------------------------
📌 MODAL PROVIDER
------------------------------------------------------
Crear src/providers/ModalProvider.tsx

Hará:
- Escuchar el store
- Tomar el “modal actual”
- Buscar el componente real en el Registry
- Renderizarlo dentro de ModalBase
- Soportar stack (renderizar múltiples modals)
- Manejar esc y backdrop click

El provider debe montarse en App.tsx o Layout.tsx.
