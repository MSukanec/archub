Tenemos problemas graves de inconsistencias de guardado en toda la app:
- cambios que no se reflejan
- autosave poco confiable
- modales que guardan distinto
- inputs que guardan de formas diferentes

Objetivo:
Diseñar e implementar un SISTEMA DE GUARDADO CENTRALIZADO, OPTIMISTIC, CONFIABLE y ESCALABLE, estilo Notion / Linear / Stripe.

IMPORTANTE:
- Esto es una refactorización ARQUITECTÓNICA
- No es arreglar bugs puntuales
- No romper funcionalidades existentes
- Hacerlo incremental

---

## PRINCIPIOS OBLIGATORIOS

1) Single Source of Truth
- El estado real vive en React Query
- Los componentes NO guardan directamente

2) Optimistic Updates
- La UI se actualiza instantáneamente
- El backend confirma después
- Rollback automático si falla

3) Centralización absoluta
- Ningún componente puede:
  - llamar Supabase
  - hacer fetch
  - invalidar queries manualmente

4) Unificación de flujos
- Inputs
- Modales
- Forms
- Toggles
- Todos usan el MISMO sistema

---

## ARQUITECTURA A IMPLEMENTAR

Crear un módulo central:

/core/save-engine/

Debe incluir:
- saveEngine.ts
- useAutoSave.ts
- useOptimisticMutation.ts
- saveQueue.ts

Responsabilidades:
- debounce
- batching
- optimistic update
- commit real
- rollback
- estado global de guardado

---

## COMPORTAMIENTO ESPERADO

- onChange → optimistic update inmediato
- debounce configurable
- commit automático
- error → rollback
- cache sincroniza TODA la UI
