🧱 DEFINICIÓN DE NIVELES (NO CAMBIAR)
🔹 Nivel 0 — UI Primitives

📁 src/components/ui

Componentes atómicos y visuales: Card, Button, Badge, Avatar, etc.

NO conocen negocio

NO conocen dashboards

NO manejan datos

❗️NO mover nada acá
❗️NO agregar lógica nueva

🔹 Nivel 1 — Charts (puros, agnósticos)

📁 src/components/charts

Reglas estrictas:

Son gráficos puros

NO usan Card

NO tienen títulos

NO manejan layout

Solo reciben data, config, height, etc.

Ejemplos válidos:

MonthlyTrendChart

CategoryBreakdownChart

👉 Si existe un chart duplicado dentro de dashboard/, debe eliminarse o reemplazarse por el del Nivel 1.

🔹 Nivel 2 — Dashboard Blocks

📁 src/components/dashboard

Reglas:

Son bloques reutilizables de dashboard

SI usan Card

SI combinan UI + charts + métricas

SI definen tamaños, jerarquía visual y layout interno

NO conocen páginas específicas (no “general costs”, no “materials”, etc.)

Ejemplos válidos:

KPICard

ChartCard

StatCard

MetricCard

❌ No deben existir charts puros acá
❌ No deben existir duplicados de components/charts
