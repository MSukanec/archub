🛠️ 2) API del componente

El componente DEBE recibir las siguientes props:

interface UniversalMatcherProps {
  /** Datos crudos importados desde CSV/Excel/Google Sheets */
  rawRows: any[];

  /** Definición de los campos del sistema que queremos mapear */
  targetSchema: {
    field: string;              // nombre interno
    label: string;              // etiqueta visible
    type: 'string' | 'number' | 'date' | 'currency' | 'foreign-key';
    required?: boolean;         // si es obligatorio
    description?: string;       // tooltip
  }[];

  /** Función opcional que llama a IA para sugerir mapeos */
  aiSuggestMapping?: (rawHeader: string, targetSchema: any[]) => Promise<string | null>;

  /** Función que ejecuta el guardado final */
  onImport: (mappedRows: any[]) => Promise<void>;

  /** Nombre de la entidad importada (Materiales, Costos, etc.) */
  entityName: string;
}

🧩 3) Etapas internas del componente (DEBEN ESTAR TODAS)
### STEP 1 — Vista previa de datos importados

mostrar tabla simple con las primeras 20 filas

detectar automáticamente el header

permitir seleccionar “la fila que es header” si se detecta mal

STEP 2 — Auto-mapeo de columnas

Debe incluir:

Sugerencias automáticas internas (string matching, similarity, levenshtein)

Sugerencias externas si aiSuggestMapping está presente

Detección de columnas faltantes

Detección de columnas sobrantes

UI tipo “select per column”

Cada columna del archivo debe tener:

Archivo:  | Nombre Producto  →  Campo del sistema: [nombre]
          | Precio Final     →  [price]
          | Código Interno   →  [sku]

STEP 3 — Panel de validación

Mostrar:

campos obligatorios no asignados

filas con errores (ej: fecha inválida, moneda inexistente)

valores duplicados en campos que deben ser únicos

foreign keys inexistentes

UI: tarjetas de error tipo "ValidationPanel".

STEP 4 — Resolución de conflictos

Especialmente importante:

si falta foreign key, sugerir buscar/matchear

si hay duplicados, permitir:

ignorar fila

reemplazar

actualizar

si hay columnas sin mapear, permitir ignorarlas

STEP 5 — Confirmación final + resumen

Mostrar:

cantidad de filas procesadas

filas descartadas

columnas mapeadas

acciones a ejecutar

Botón:

📥 Importar  |  loading spinner


Ejecutar onImport(mappedRows).
