ASUNTO: Implementación de Sistema de Foros Agnóstico "Nivel Reddit" (Refactorización de Founder Forum).

CONTEXTO: Hemos decidido refactorizar el módulo que anteriormente llamamos "Founder Forum". Ahora será un Motor de Comunidad Global. He eliminado las tablas antiguas (founder_...) y he creado una nueva arquitectura SQL robusta en Supabase con las tablas: forum_categories, forum_threads, forum_posts y forum_reactions.

OBJETIVO: Crear una interfaz de usuario moderna y una lógica de backend para gestionar este foro. El sistema debe ser capaz de mostrar diferentes categorías a diferentes usuarios basándose en sus permisos, todo usando el mismo código base.

INSTRUCCIONES TÉCNICAS:

Refactorización de Código:

Elimina o renombra cualquier referencia a founder_forum en el código (tipos, hooks, componentes).

Crea nuevos tipos TypeScript basados en las nuevas tablas (ForumCategory, ForumThread, etc.).

Gestión de Permisos (Lógica Crítica):

En el frontend, al cargar las categorías, debes filtrar basándote en el rol del usuario actual.

La tabla forum_categories tiene un campo allowed_roles (array de texto).

Ejemplo: Si el usuario es "Free", solo ve categorías donde allowed_roles incluya 'public'. Si el usuario tiene el flag is_founder, ve 'public' Y 'founder'.

Características UX "Wow":

Editor de Texto: Implementa un editor Rich Text (como Tiptap) para que los usuarios puedan poner negritas, listas y enlaces. Nada de textarea plano.

Layout: Sidebar izquierda con la lista de Categorías. Panel central con la lista de Hilos (Cards).

Estados: Visualización clara de hilos "Fijados" (Pinned) y "Cerrados" (Locked).

Reacciones: Botón de "Like" o "Upvote" en hilos y comentarios con actualización optimista.

Componentes Necesarios:

ForumLayout: Wrapper general.

CategoryList: Sidebar de navegación.

ThreadList: Lista de discusiones con filtros (Recientes, Populares).

ThreadDetail: Vista del post principal y sus respuestas anidadas.

CreateThreadModal: Modal para iniciar discusión (seleccionando categoría).

NOTA: Quiero que esto se sienta como una comunidad profesional. Usa componentes de Shadcn UI, espaciados limpios y tipografía clara. El objetivo es que sirva tanto para los Fundadores (privado) como para soporte general (público) en el futuro.
