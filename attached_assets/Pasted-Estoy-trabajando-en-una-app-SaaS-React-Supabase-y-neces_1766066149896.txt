Estoy trabajando en una app SaaS (React + Supabase) y necesito agregar una nueva sección de gestión de Roles y Permisos a nivel organización.

CONTEXTO ACTUAL:
- Ya existe una página "Miembros" donde se invitan usuarios y se les asigna un rol.
- Los roles existentes por organización son: Administrador, Editor y Lector.
- Los permisos están modelados en Supabase con tablas:
  - roles
  - permissions
  - role_permissions
- El backend ya garantiza que:
  - Administrador tiene TODOS los permisos
  - Editor y Lector tienen subconjuntos configurables

OBJETIVO:
Crear una nueva pestaña dentro de la página de Organización llamada:
👉 "Roles y permisos"

ESTRUCTURA DE LA UI:
1) Tabs dentro de Organización:
   - Miembros
   - Roles y permisos   ← NUEVA

2) En "Roles y permisos" mostrar:
   - Una lista de roles (cards o accordion):
     - Administrador
     - Editor
     - Lector

3) Para cada rol:
   - Mostrar lista de permisos agrupados por categoría (category de permissions)
   - Cada permiso se muestra como:
     [checkbox] Nombre del permiso
     Descripción corta debajo

COMPORTAMIENTO:
- Rol Administrador:
  - Checkboxes deshabilitados
  - Todos activos
  - Mostrar texto: "Este rol tiene acceso total por defecto"

- Rol Editor y Lector:
  - Checkboxes editables
  - Cambios NO se guardan automáticamente
  - Botón explícito: "Guardar cambios"

DATOS:
- Obtener permisos desde Supabase:
  - permissions
  - role_permissions filtrado por role_id
- Al guardar:
  - Reemplazar los permisos del rol (delete + insert en role_permissions)
  - Mostrar feedback visual (loading / success / error)

UX:
- UI clara, sin ruido
- Mostrar advertencia:
  "Los cambios de permisos afectan a todos los miembros con este rol"
- Mantener consistencia visual con la página de Miembros

SEGURIDAD:
- Si el usuario no tiene permiso 'roles.manage':
  - Mostrar la vista en modo solo lectura
  - Ocultar botones de guardado

ENTREGABLES:
- Componentes React necesarios
- Hooks de datos (useRoles, usePermissions, etc.)
- Ejemplo de queries Supabase
- Estructura de archivos recomendada

No modifiques lógica existente de Miembros.
Agregá esta funcionalidad como una extensión limpia y modular.
