Tengo un problema crítico con mi "Announcement Bar" (barra de anuncios) en dispositivos móviles.

La situación actual: En escritorio, la barra se ve perfecta: el texto, los dos botones y el icono de cerrar "X" están todos en una sola fila horizontal. El problema es que en el celular, como no hay espacio horizontal, el diseño sigue forzando esa única fila. El resultado es que el texto del anuncio se corta drásticamente (solo se ven unas pocas letras y puntos suspensivos) para dar espacio a los botones. Esto hace que el anuncio sea inútil en móviles.

El objetivo (La solución que necesito): Quiero que modifiques el CSS (y el HTML si es estrictamente necesario) para hacer la barra responsiva.

Necesito que implementes una Media Query para pantallas pequeñas (por ejemplo, menos de 768px o el breakpoint que consideres estándar para móviles).

Dentro de esa media query, el comportamiento debe cambiar a esto:

Cambio de Dirección: El contenedor principal de la barra debe cambiar su dirección de flex de row a column (o usar flex-wrap: wrap de forma inteligente) para que los elementos se apilen verticalmente.

Texto Completo: El elemento del texto debe tener permiso para ocupar el 100% del ancho, ajustar su texto en múltiples líneas (white-space: normal o similar) y NO truncarse con text-overflow: ellipsis. El mensaje debe leerse completo.

Reubicación de Botones: Los dos botones ("Dudas" y "Ver Beneficios") deben moverse para estar debajo del bloque de texto. Dependiendo del espacio, pueden estar en su propia fila horizontal debajo del texto, o apilarse verticalmente uno sobre otro, lo que sea más fácil de usar con el dedo.

Posición de la "X": El icono de cerrar debe mantenerse siempre accesible, idealmente en la esquina superior derecha del contenedor de la barra, quizás usando posicionamiento absoluto relativo a la barra, para que no se mueva cuando el texto crece.

Por favor, analiza mi código actual y dame el CSS corregido (y HTML si cambió) que implemente este comportamiento de apilamiento responsivo para móviles, asegurando que el texto siempre se lea completo.
