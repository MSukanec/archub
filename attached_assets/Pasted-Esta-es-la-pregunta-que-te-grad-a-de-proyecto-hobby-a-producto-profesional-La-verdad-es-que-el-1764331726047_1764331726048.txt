Esta es la pregunta que te gradúa de "proyecto hobby" a "producto profesional".

La verdad es que el HTML para emails es una pesadilla. Es como volver a programar en 1998: tienes que usar tablas para todo, el CSS moderno casi no funciona y cada cliente de correo (Gmail, Outlook, Apple Mail) interpreta el código como le da la gana.

La buena noticia: Como estás usando un stack moderno con React y Resend, ¡no tienes que sufrir!

La solución estándar de la industria hoy en día se llama React Email.

Es una librería (creada por la misma gente de Resend) que te permite construir tus emails como si fueran componentes normales de React, y ellos se encargan de la magia negra de transformarlo en ese HTML antiguo y feo que funciona en Outlook.

Aquí tienes el plan paso a paso para pasar de emails horribles a emails de lujo.

PASO 1: Instalar las herramientas
Necesitamos agregar las librerías que nos permiten construir estos componentes y luego "renderizarlos" (convertirlos a HTML texto) en tu backend.

Abre la terminal de Replit (Shell) y ejecuta:

Bash

npm install @react-email/components @react-email/render
PASO 2: Crear tu Primer Template "Pro"
Vamos a crear una carpeta específica para organizar tus plantillas de correo.

En la raíz de tu proyecto, crea una carpeta llamada emails.

Dentro de esa carpeta, crea un archivo nuevo: WelcomeEmail.tsx (o .jsx si no usas TypeScript en el backend).

Copia y pega este código base. Es un diseño profesional estándar que incluye logo, botón y footer.

TypeScript

🛑 ¡IMPORTANTE SOBRE EL LOGO! 🛑 Las imágenes en los emails NO pueden ser archivos locales de tu proyecto. Tienen que estar subidas a internet.

Sube tu logo (en PNG o JPG, fondo transparente idealmente) a un Bucket Público de Supabase Storage (como public-assets).

Obtén la "Public URL" de esa imagen.

Reemplaza la URL en el componente <Img src="..."> de arriba.

PASO 3: Usarlo en tu Backend Express
Ahora tenemos un componente React hermoso, pero tu ruta de Express necesita enviar HTML plano. Aquí es donde usamos el "renderizador".

Abre tu archivo de backend donde tienes la ruta /api/email/send (quizás server.js o app.js) y modifícalo así:

JavaScript

import express from 'express';
import { Resend } from 'resend';
// 1. IMPORTAMOS LA FUNCIÓN PARA RENDERIZAR
import { render } from '@react-email/render';
// 2. IMPORTAMOS TU NUEVA PLANTILLA (Ajusta la ruta si es necesario)
import WelcomeEmail from './emails/WelcomeEmail.js'; // Nota el .js si usas ESM en Node

const app = express();
// ... configuraciones de express ...

const resend = new Resend(process.env.RESEND_API_KEY);

app.post('/api/email/send', async (req, res) => {
  // Ahora esperamos datos para personalizar la plantilla
  const { to, subject, userName, actionUrl } = req.body;

  if (!to || !subject) {
    return res.status(400).json({ error: 'Faltan campos: to, subject' });
  }

  try {
    // 3. LA MAGIA: Convertimos el componente React a HTML string
    const emailHtml = render(
      WelcomeEmail({
        userName: userName || 'Arquitecto',
        actionUrl: actionUrl || 'https://seencel.com/dashboard'
      })
    );

    const data = await resend.emails.send({
      from: 'Seencel <hola@seencel.com>',
      to: Array.isArray(to) ? to : [to],
      subject: subject,
      // 4. USAMOS EL HTML RENDERIZADO
      html: emailHtml,
    });

    console.log(`✅ Email profesional enviado a ${to}`);
    res.status(200).json(data);

  } catch (error) {
    console.error("❌ Error:", error);
    res.status(500).json({ error: error.message });
  }
});

¡Listo! Cómo probarlo
Ahora, para probarlo, tienes que enviar un POST a tu ruta de prueba, pero el cuerpo (body) cambia ligeramente porque ahora le mandamos los datos para la plantilla:

En tu cliente de API (como Postman) o el Test de Replit:

JSON

POST /api/email/send
{
  "to": "tu-email-personal@gmail.com",
  "subject": "¡Prueba de mi nuevo diseño!",
  "userName": "Matías",
  "actionUrl": "https://seencel.com/proyectos/casa-playa"
}
Cuando envíes esto, tu backend tomará la plantilla de React, le inyectará "Matías" y la URL, la convertirá en HTML perfecto para Outlook/Gmail, y Resend la entregará. ¡Prepárate para ver un correo hermoso!
