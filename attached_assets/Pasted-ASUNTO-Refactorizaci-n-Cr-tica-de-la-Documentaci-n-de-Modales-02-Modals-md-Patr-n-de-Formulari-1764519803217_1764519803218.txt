Nuevo Estándar: Formularios Agnósticos y Reutilizables
Para garantizar la máxima reutilización y mantenibilidad, separamos la lógica del formulario de su contenedor visual (el modal).

1. El Componente del Formulario Puro (Lógica de Negocio)
Este componente vive en la carpeta de su feature correspondiente (ej: src/features/projects/components/). No tiene headers, footers ni estilos de modal. Solo inputs y lógica.

TypeScript

2. El Componente del Modal Contenedor (Estructura Visual)
Este componente vive en la carpeta global de modales (src/components/modals/). Es un contenedor "tonto" que usa los componentes de UI estándar y renderiza el formulario lógico en su interior.

TypeScript

// src/components/modals/projects/CreateProjectModal.tsx

import { Dialog, DialogContent, DialogHeader, DialogTitle } from '@/components/ui/dialog';
import { FormModalBody } from '@/components/ui/form-modal-body'; // Componente estandarizado
import { useCreateProjectModal } from '@/hooks/modals/useCreateProjectModal'; // Hook de estado zustand
import { CreateProjectForm } from '@/features/projects/components/forms/CreateProjectForm';

export const CreateProjectModal = () => {
  // El estado de apertura/cierre lo maneja un hook global (zustand)
  const { isOpen, onClose } = useCreateProjectModal();

  return (
    <Dialog open={isOpen} onOpenChange={onClose}>
      <DialogContent className="sm:max-w-[600px] p-0 gap-0 overflow-hidden">
        {/* Header Compacto estilo Lemon Squeezy */}
        <DialogHeader className="px-6 py-4 border-b bg-muted/10">
          <DialogTitle className="text-lg font-semibold">
              Crear nuevo proyecto
          </DialogTitle>
        </DialogHeader>

        {/* Cuerpo del modal con scroll interno si es necesario */}
        <FormModalBody>
          {/* INYECCIÓN DEL FORMULARIO AGNÓSTICO */}
          {/* Le pasamos onClose como prop onSuccess para que el modal se cierre al terminar */}
          <CreateProjectForm onSuccess={onClose} />
        </FormModalBody>

        {/* No es necesario un DialogFooter si el botón está dentro del form */}
      </DialogContent>
    </Dialog>
  );
};
