PASO 4 (Versión Express): Preparar tu Backend
Necesitamos hacer tres cosas en tu proyecto de Replit para que tu servidor Express pueda enviar correos.

1. Instalar la librería de Resend
En Node.js (Express), es mucho más fácil usar la librería oficial de Resend que hacer llamadas fetch manuales.

Abre la Shell (terminal) en Replit.

Ejecuta este comando:

Bash

npm install resend
2. Guardar el Secreto en Replit
Tu servidor Express necesita la API Key, pero no podemos ponerla en el código. En Replit, esto se maneja en la sección de "Secrets" (Secretos).

En la barra lateral izquierda de Replit, busca el icono de un candado 🔒 llamado "Secrets" (o "Environment Variables").

Haz clic para abrir el panel.

Key (Clave): Escribe RESEND_API_KEY.

Value (Valor): Pega la llave que copiaste de Resend (la que empieza con re_...).

Haz clic en "Add new secret".

Ahora, tu código de Express podrá acceder a esta clave usando process.env.RESEND_API_KEY.

3. Crear la Ruta (Route) en Express
Necesitamos crear una "puerta" en tu servidor Express que escuche los avisos de Supabase. Será una ruta POST específica.

Como no sé exactamente cómo tienes organizada tu estructura de carpetas en Express, te daré el código de la ruta y tú (o Replit) pueden colocarlo donde definan sus rutas (por ejemplo, en app.js, server.js o en un archivo dedicado como routes/webhooks.js).

Dale estas instrucciones a Replit para crear la ruta:

Plaintext

Necesito crear una nueva ruta POST en mi servidor Express para manejar webhooks de notificaciones.

1. Asegúrate de que la librería 'resend' esté importada al principio del archivo donde se definen las rutas:
import { Resend } from 'resend';

2. Inicializa el cliente de Resend usando la variable de entorno:
const resend = new Resend(process.env.RESEND_API_KEY);

3. Crea esta ruta POST. Por ahora, será una ruta de prueba simple para verificar que todo funciona.

El código de la ruta debe ser este:

// Ruta para probar la conexión con Resend (Webhook Test)
app.post('/api/webhooks/test-email', async (req, res) => {
  console.log("🔔 Webhook de prueba recibido!");

  try {
    // Intentamos enviar un correo de prueba simple
    const data = await resend.emails.send({
      from: 'Seencel System <sistema@seencel.com>', // ¡IMPORTANTE: Usa TU dominio verificado aquí!
      to: ['TU_EMAIL_PERSONAL@gmail.com'], // ¡IMPORTANTE: Pon TU email personal para recibir la prueba!
      subject: 'Prueba de conexión Express + Resend 🚀',
      html: '<p>¡Funciona! Tu backend Express en Replit puede enviar correos.</p>'
    });

    console.log("✅ Correo de prueba enviado:", data);
    res.status(200).json({ message: "Test exitoso", data });

  } catch (error) {
    console.error("❌ Error enviando correo de prueba:", error);
    // Es importante devolver un error 500 si falla, para que el webhook sepa que hubo un problema.
    res.status(500).json({ error: error.message });
  }
});
Lo que tienes que hacer tú antes de pedirle esto a Replit:

En el código de arriba, fíjate en los comentarios que dicen ¡IMPORTANTE!.

Donde dice sistema@seencel.com, asegúrate de usar el dominio que verificaste en Resend.

Donde dice TU_EMAIL_PERSONAL@gmail.com, pon tu dirección de correo real para recibir la prueba.
